## Решения ведущего сценариста

### 1. Сундук чудес — 700 кликов (принято)

**Решение:** `clicksToOpen` = **700** (было 1000). Первое открытие в неделю — по-прежнему **бесплатно**. Прогресс **не сгорает** в понедельник.

**Психология и реклама:** да, при 700 игрок **чаще** нажмёт rewarded, если:
- видит, что до цели **2–4 дня**, а не «вечность»;
- реклама даёт **ощутимый скачок** (рекомендация: +150–200 к прогрессу или «открыть сейчас» раз в неделю);
- кот формулирует как **короткий путь**, не как «заплати»: *«До чуда 180 удачи. Домовой знает лазейку — один раз на неделе.»*

**Риск:** слишком частые «почти открыл» + агрессивная реклама = ощущение дойки. Баланс: прогресс-бар в HUD, мягкий тон кота, лимит rewarded на прогресс сундука — **не чаще 1 раза в день**.

**Канон для реализации:** `loot_tables.md` / `miracleChest.clicksToOpen` → 700; HUD: `Удачи до чуда: N/700`.

### 2. Энергия — вариант B (принято)

**Решение владельца:** **B — мягкий буфер.**

| Параметр | Было | Стало |
|----------|------|-------|
| Старт энергии / max | 100 / 100 | **120 / 120** |
| Реген | 1 / мин (60 / ч) | **1.2 / мин (72 / ч)** |
| Клик по коту | −1 энергия | без изменений |
| Онбординг | клик бесплатен, квесты 0 энергии | без изменений |
| Награды (+5 max Банник и т.д.) | как в каноне | без изменений |

**Эффект для игрока:**
- ~**2–2,5 мин** активного клика на полном баре (было ~1,5–2 мин);
- полный бар с нуля ≈ **1ч40м** (было то же по времени, но потолок выше — 120 вместо 100);
- пассивно за сутки (если заходить несколько раз): до **~72** энергии от регена на базовом max, плюс бонусы от квестов.

**Позиция сценариста:** 5 минут в день — нормальная сессия, если в ней есть **событие** (сундук, монетка кота, дух, Суседко). Клик — фон. Вариант B даёт чуть больше «лапы» в D2–D7 без ломки экономики и без привязки к рекламе.

**Канон для реализации:** `gameConstants.ts` — `START_ENERGY`, `START_MAX_ENERGY` → 120; `BASE_REGEN_RATE` → 72/ч (или эквивалент 1.2/мин); миграция save: существующие игроки с max 100 → поднять max до 120 и energy `min(energy+20, 120)` при первом входе после патча (уточнить в `saveMigration.ts` на этапе dev).

### 3. Удержание — принятые интерактивы

Из 15 идей в **MVP** входят:

#### 3.1 «Кот нашёл» (принято)

- **Раз в день** (или после N часов оффлайна) на сцене появляется кликабельная **монетка** (тот же FX, что при клике по коту).
- Награда: **+10 энергии** (может превышать max — как у Полевого; в HUD: текущая / макс.).
- Кот (сноска, один раз): *«Я тут кое-что припрятал. Не спрашивай что.»*
- **На перспективу:** тот же слот/механика может дропать предметы (сметана, оберег) — единый тип события `dailyFind` в save.

#### 3.2 Клики по предметам сцены — реплика кота (принято)

- Клик по **некликабельным** объектам комнаты 1: **печка, скамейка, окно** (не трофеи, не мебель с игровой логикой).
- Кот отвечает **короткой забавной репликой** (пул 2–3 на объект, без повтора подряд).
- Формат: сноска `.cat-dialog--footnote`, **не блокирует** сцену.
- Примеры:
  - Печка: *«Туда лезь сам. Я уже обжёг ус.»*
  - Скамейка: *«Садись. Суседко всё равно под половицу залезет.»*
  - Окно: *«В лесу сегодня тихо. Подозрительно тихо.»*
- Тексты — `instruction/cat_dialogs.md` (новая секция «Предметы избы»).

**Не в MVP из списка 15:** поглаживание, серии кликов, мини-квест «принеси» — в backlog.

### 4. Zzz при сне (принято)

- **Только визуал:** 2–3 буквы «z» над спящим **котом** (`sleep`), CSS float, loop ~2 s.
- **Без реплик** при пробуждении и без Zzz у Суседко/домового/Жирдяя.
- `prefers-reduced-motion`: без анимации Zzz.

---

### 5. Сказки в книге после победы (принято)

**UX:**
- После победы над духом на развороте бестиария — кнопка **«Сказка»** (деревянная, под «В путь»; не stretch на всю колонку).
- Тап → **тот же разворот**, контент переключается в режим сказки: **2–4 страницы**, листание стрелками как у бестиария.
- Кнопка **«К духу»** — возврат к карточке духа.
- Иллюстрация справа — та же 3D-иллюстрация духа; лёгкий золотой shimmer на пергаменте (см. п. 7 дизайнера).

**Контент:**
- Сценарист **не выдумывает** былины — адаптированные народные тексты / пересказы.
- Файлы: `instruction/folktales/{spirit_id}.md` (источник, сокращение, возрастной фильтр).
- MVP: 1–2 сказки (например Банник, Леший) как образец пайплайна; остальные — по мере готовности текстов.

**Кот (опционально, одна сноска при первом открытии сказки):** *«Предки у печки так рассказывали. Я только про веник добавил.»*

## Решения гейм-дизайнера UI/UX

### 6. Idle-анимация кота и домового (принято)

| Персонаж | Эффект | Техника |
|----------|--------|---------|
| Кот `sit` | дыхание | `scale(1 → 1.02)`, 4–6 s, `transform-origin: bottom center` |
| Кот `sleep` | покой + Zzz | лёгкий `translateY(1px)` + слой `.cat-zzz` |
| Домовой | жизнь в углу | fade-in при появлении + bob 2 px, 3–4 s loop |

- Новые PNG для MVP **не требуются** — CSS на существующих спрайтах.
- `prefers-reduced-motion`: только opacity-pulse, без bob/scale.

---

### 7. Волшебная анимация в книге (принято)

| Момент | Эффект |
|--------|--------|
| Открытие книги | 6–8 золотых частиц от корешка (`.book-sparkle`, CSS) |
| Листание | `translateX` + лёгкий `rotateY(2deg)` пергамента |
| Победа / unlock духа | одноразовый burst на иллюстрации, класс `.book-spirit--unlocked`, ~1.5 s |
| Locked-дух | desaturate + силуэт (гравюра-fallback) |
| Кнопка «В путь» / «Сказка» | золотой pulse 1.6 s (как hover книги на сцене) |
| Режим сказки | лёгкий shimmer пергамента |

**Запрещено:** full-screen particles, неон, векторные «магические» иконки.

**Mockup:** не запрашивался (spec_only); при реализации сверять с `book_layout.md` и таблицей Layout vs mockup.

### 8. Оживление игры — принятые пункты

| ID | Что | Спека |
|----|-----|-------|
| **8.1** | Сундук пульсирует, когда готов | Усилить glow на `.room-chest--ready`; отличим от неготового |
| **8.3** | Parallax леса при pan 1→2 | Лёгкий сдвиг `.window-aperture__forest` при `translateX` комнаты |
| **8.4** | Трофей на полке — первое появление | `scale-in` + короткий блик при установке |

| **8.7** | Викторина — feedback | Верный ответ: зелёная вспышка пергамента; спасение оберегом: золотой щит 0.3 s |

**Не принято в этом раунде:** 8.2 (разные иконки монет), 8.6 (полоска регена HUD), 8.8 (профиль locked), 8.9 (FX Сундука чудес отдельно), 8.10 (звук).

#### 8.10 Звук — статус

**Генерировать полноценные SFX «как у саунд-дизайнера» Cursor не может.** Варианты для `dev`:

| Вариант | Описание |
|---------|----------|
| **A** | Подключить **royalty-free** пак (шорох книги, «динь» монеты, мурлык) — владелец кладёт файлы в `assets/audio/` |
| **B** | Минимальные **Web Audio API** бипы в коде (простой, «дешёвый» звук) |
| **C** | Скрипт + **ffmpeg** для синтеза коротких wav (можно сделать на этапе dev, качество среднее) |

**Рекомендация дизайнера:** P2; для MVP достаточно **одного** звука открытия сундука + опционально монета. Ждёт выбора A/B/C от владельца.
