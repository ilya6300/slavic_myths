## 1. UX-решение

### Что видит игрок

Одна главная сцена — **изба-хаб**. Игрок сразу видит кота в центре, книгу справа внизу, слева сверху — **морду кота и титул**, расходники в HUD и (после Суседко) сундуки у стены. Печка, скамейка, Домовой — атмосфера; ночью — Жирдяй **за стеклом** (`izba_scene_layers.md`).

| Элемент | Интерактив | Приоритет |
|---------|------------|-----------|
| Кот | Да — клик, монетки удачи | **Главный** |
| Книга «Тайны славянских духов» | Да — бестиарий | **Высокий** |
| Обычный сундук (3 ч) | Да — лут | Высокий |
| Сундук чудес (еженед.) | Да — фрагменты / эпик-лут | Высокий (когда активен) |
| Стрелка «Трофеи →» | Да — комната 2 | Средний |
| Печка, скамейка, Домовой | Нет | Фон / награда |
| Окно | Нет (клик по окну не нужен) | Фон |
| HUD: аватар кота | Да — открывает профиль | Высокий |
| HUD: сметана | Да — +100 энергии к текущему балансу (cap = макс.) | По необходимости |

### Принцип адаптива

**Один дизайн для ПК и телефона.** Скин избы не совпадает с пропорциями широкоформатного экрана — камера **центрирует** сцену так, чтобы в кадре комнаты 1 всегда были **окно, кот и книга** (safe-frame, `izba_scene_layers.md` §1.6.1).

На узком / portrait экране сцена **горизонтально прокручивается** (swipe / scroll), старт — **центр на коте**. HUD и диалог кота — `position: fixed`, не скроллятся.

### Переход в комнату трофеев

`izba_scene_layers.md` §2 (pan, hover края, свайп, две комнаты на одном inner).

## 2. Система координат

Все позиции комнаты 1 — **проценты от** `.izba-scene__inner` (левая половина панорамы, `0–50%` inner). Стек DOM и z-index — **`izba_scene_layers.md` §1**.

- **Ось X:** `0%` — левый край, `100%` — правый.
- **Ось Y:** якорь `transform-origin: bottom center` — объект «стоит на полу».
- **Размер:** `width` в `%`; высота через `aspect-ratio` ассета.

### Базовый viewport

| Устройство | Соотношение | Поведение |
|------------|-------------|-----------|
| Desktop / landscape widescreen | viewport устройства | Inner центрируется по safe-frame (окно + кот + книга); края могут обрезаться |
| Mobile portrait | `16 / 9`, inner `200%` (панорама избы) | Horizontal pan + scroll-snap: печка / кот / книга+сундуки |
| Tablet landscape | Как desktop | Safe-frame + полный pan при необходимости |

### 4.4.1. Подписи на полу (диегетик, оба сундука)

Владелец (скрин 2026-09-11): часы над крышкой выглядят дешёвым HUD; схема — **трапеция на досках** у ножек сундука (дальняя сторона уже, ближняя к камере шире). Эпик: вернуть **бар с заливкой**, не голый счёт `0/700`.

**Решение игрока:** обычный — «сколько ждать / можно открыть»; чудес — «сколько кликов до следующего открытия / уже готов». Данные на **сцене**, не в шапке (`hud_layout.md`: `.hud-miracle` снят).

| Правило | Как |
|---------|-----|
| Где | доски **перед** сундуком, в зоне схематичной трапеции; ковёр кота не перекрывать |
| Геометрия | CSS 3D: `perspective` + `rotateX(55–65deg)`, `transform-origin: top center`. Дальний край ≈ ширина основания сундука, ближний **×1.15–1.3**. Дальний край **заходит под** ножки спрайта |
| Слои | `.scene-chest-floor` `z-index` **ниже** спрайта; wrap `overflow: visible`. Сундук рисуется поверх дальнего края «надписи» |
| Материал | выжженные / врезанные в пол знаки: тёмная выемка + тёплый блик по верхней кромке глифа. **Не** плоский `#f0c14a` с `text-shadow` в воздухе |
| Hit | `pointer-events: none` — клик всегда в сундук |
| Спрайт | **не** увеличивать `width` сундука «под подпись» |
| Ночь | читается на `.layer-night`: тёмная пластина-выемка, не тонкий текст на брёвнах |
| Ассет | P0 = CSS; новый PNG не нужен |

Общий класс: `.scene-chest-floor`. Модификаторы: `--timer`, `--progress`.

**Антипример:** `bottom: 100%` + золотой span над крышкой; Material `linear-progress`; возврат чипа `.hud-miracle` в шапку; `mix-blend-mode` вместо выемки.

#### Таймер обычного сундука (`.scene-chest-floor--timer`)

| Состояние | Пол |
|-----------|-----|
| Кулдаун | цифры `h:mm:ss` / `m:ss` (`formatCooldownMs`), табличные; тик раз в 1 с |
| Готов | подпись **скрыта** — говорит пульс спрайта |

#### Прогресс сундука чудес (`.scene-chest-floor--progress`)

| Состояние | Пол |
|-----------|-----|
| Бесплатный слот недели | бар **скрыт** — готовность = свечение спрайта |
| Гриндинг (`weekSlotUsed`, клики `< 700`) | **дорожка + заливка + `n/700` на баре** |
| Набрано 700, ещё не открыт | заливка 100% + свечение сундука; `700/700` до открытия |
| После открытия | сброс; снова гриндинг с `0/700` и пустой заливкой |

Бар — не «число рядом»:

| Часть | Вид |
|-------|-----|
| Дорожка | выемка в досках, `rgba(18, 10, 6, 0.82)`, высота до 3D ~10–12px, ширина ≈ основание сундука |
| Заливка | `--chest-progress: 0…1` (runtime), аметист в тон `.scene-chest-miracle--glow` (`#5a2a7a` → `#c4a0e8`). Ширина = прогресс. `transition: width 180ms ease-out` на клик |
| Счёт | `n/total` **поверх** заливки, тот же `rotateX`, `#f5e6d0`, `tabular-nums`. Не вместо бара |
| A11y | `role="progressbar"`, `aria-valuenow/min/max` |

Второй сигнал (цвет не один): ширина заливки + цифры; готовность — пульс спрайта, не «бар позеленел».

Juice: клик по коту → заливка подрастает (не молча). Достижение 700 → заливка доходит до края, сундук пульсирует.

Проверить: ночь; pan 1→2; оба сундука сразу (таймер + бар не слипаются); длинный `12:00:00`; `0/700` и `700/700`.

## 11. Состояния и анимации

| Элемент | Idle | Hover | Active / особое |
|---------|------|-------|-----------------|
| Кот | sit/sleep | scale 1.02 | squash + монетка |
| Книга | pulse | свечение контура | полёт в центр → open → бестиарий (`book_layout.md`) |
| Сундук 3ч | closed | пульс крышки | open + modal |
| Сундук чудес | FX свечение | усиленный FX | open + epic modal |
| Сметана HUD | — | scale 1.05 | confirm → full energy |
| Жирдяй | покачивание 4s | — | scare event (`izba_scene_layers.md` §1.5) |
