## 1. Идея для игрока (в одном абзаце)

Ты — человек, у которого в избе живёт кот, видящий духов. Вместе вы собираете «Тайны славянских духов»: кликаете удачу, гоняете Барабашку, открываете сундук раз в несколько часов и проходите викторины без ошибок. За 30–90 секунд всегда есть маленькая победа; за неделю — коллекция и знакомство с живой славянской мифологией.

**Жанр:** кликер + коллекционирование + познавательная викторина.  
**Платформа:** Яндекс.Игры (стек — `dev/technical_requirements.md` §2).  
**Стиль:** 2D пластилин, яркий, тёплый.  
**Тон:** домашний, ироничный, с уважением к фольклору. Кот — проводник, не лектор.

## 4. Онбординг-скрипт (6 шагов)

**Зачем:** без ведения за руку новичок кликает кота в пустоту и уходит. Со скриптом он за **одну сессию (&lt; 8 минут)** проходит полный цикл: квест → награда → сундук → причина вернуться.

**Цель по времени:**

| Этап | Целевое время |
|------|----------------|
| Шаги 0–1 (приветствие + книга) | &lt; 90 с |
| Шаг 2 (Домовой, 3 вопроса) | ~2 мин |
| Шаг 3 (осмотр награды) | ~30 с |
| Шаг 4 (Суседко, 4 вопроса) | ~3 мин |
| Шаг 5 (первый сундук) | ~1 мин |
| Шаг 6 (прощание кота) | ~30 с |
| **Итого до сундука** | **&lt; 8 мин** |

### 4.1. Таблица шагов

| Шаг | Что видит игрок | Что делает | Награда / крючок |
|-----|-----------------|------------|------------------|
| 0 | Изба, кот, книга. Сундука нет | Читает приветствие (сноска снизу: голова кота + текст) | Эмоция «я хранитель» |
| 1 | Подсветка книги + реплика кота: «Начни с Домового. Без него в избе бардак.» | Открывает книгу | Ясная цель |
| 2 | Страница Домового: статус «Не побеждён», кнопка «В путь» | Проходит 3 вопроса | Победа |
| 3 | Домовой появляется у печки; страница «Побеждён»; открыт Суседко | Кликает кота, смотрит Домового | +удача от скина; крючок «Суседко спрятал сундук» |
| 4 | Квест Суседко (4 вопроса) | Победа | **Сундук появляется** |
| 5 | Сундук готов к **первому бесплатному** открытию (таймер = 0) | Открывает | Скин / титул / оберег — «ещё хочу» |
| 6 | Кот: «Загляни попозже — сундук снова набьётся. А ночью… не бросай меня.» | Выход / короткий клик-луп | Retention-крючок |

## 5. Бестиарий «Тайны славянских духов»

### 5.1. Страница духа

| Левая страница | Правая страница |
|----------------|-----------------|
| Имя | Цветная иллюстрация духа (`assets/illustration_book/`) |
| Краткое описание (2–3 предложения) | Грейд (бейдж) |
| Умение для игрока (если есть) | Статус |
| Кнопка действия | — |

**Статусы:**

| Статус | UI | Действие |
|--------|-----|----------|
| `available` (Не побеждён) | Яркая кнопка «В путь» | Старт викторины (−10 энергии) |
| `defeated` (Побеждён) | Галочка, «Сказ о победе» | Модалка трофея / мини-сказ |
| `locked` (Неактивен) | Затемнение + условие открытия | Подсказка кота |

Листание: стрелки влево/вправо; анимация перелистывания — `book_layout.md` §3. На первой/последней — соответствующей стрелки нет.

### 5.2. UI бестиария, который цепляет (решение вместо ???)

Не «энциклопедия», а **живая книга**:

1. **Лента прогресса глав** над разворотом: точки-главы (Дом → Двор → Лес → Поле → Эпоха чудес). Текущая глава пульсирует.
2. **Силуэты неоткрытых** вместо пустых страниц: «???» + одна дразнящая деталь («кто-то шуршит под половицами…»).
3. **Чернильная анимация** при открытии страницы (пятно → контур духа) — 0.4–0.6 с, без блокировки UI.
4. **«След кота»** на доступных квестах: лапка встроена в деревянную плашку «В путь» (без отдельного оверлея).
5. **Счётчик коллекции** в корешке: `8 / 16 духов` — постоянный FOMO без агрессии.
6. **Закладка «Следующий квест»** — прыжок к ближайшему `available`.
7. После победы — **страница «оживает»** (лёгкий idle на рисунке 2–3 с), затем спокойный defeated-стейт.

### 5.3. Порядок открытия духов (прогрессия)

**Принцип:** после Суседко — **мягкая очередь**, не стена из 6 викторин. В каждый момент обычно **1–2** духа `available`. После победы — пауза на клик / сундук / трофей; кот подсказывает следующего, не следующий экзамен подряд.

```
Глава I — Дом
  1. Домовой          → всегда available на старте
  2. Суседко          → после Домового  → НАГРАДА: сундук
  3. Банник           → после Суседко
  4. Кикимора         → после Банника

Глава II — Двор и урожай
  5. Полевой          → после Кикиморы
  6. Овинник          → после Полевого
  7. Полудница        → ключ из сундука (редкий+)

Глава III — Лес и вода
  8. Леший            → после Овинника
  9. Водяной          → после Лешего
 10. Дедушка Топтыгин → ключ из сундука
 11. Русалка          → ключ из сундука (эпик)
Глава IV — Эпоха чудес (очередь осколков = порядок страниц в книге; канон `instruction/plans/draft.md` §8)
 12. Баба-Яга         → 3 фрагмента
 13. Лада             → 3 фрагмента
 14. Велес            → 6 фрагментов
 15. Кощей            → 5 фрагментов
 16. Чудо-Юдо         → 8 фрагментов
 17. Ярило            → 8 фрагментов
 18. Перун            → 10 фрагментов, финальная глава
```

**Ритм между квестами (голос кота):** после победы — 1 реплика радости + крючок на сундук/клик/трофей; подсказку «В путь» к следующему духу — только если игрок снова открыл книгу или прошло ~30 с бездействия.

### 5.4. Фрагменты Эпохи чудес + Сундук чудес

**Задача mid/late:** после обычных духов — **ежедневка** (1 осколок за полный день, с Банника), **Сундук чудес** (доп. осколки) и **долгая глава** эпохи чудес. Очередь целей и алгоритм дропа — `instruction/plans/draft.md` §2, §8.

#### Сундук чудес (еженедельное событие)

Числа (25%, pity 8, 700 кликов, условия появления) — `dev/loot_tables.md` § «Сундук чудес».

**Важно:** «неделя» = только **бесплатный слот**. Кликовый прогресс не сгорает.

**UI / голос кота** (`cat_dialogs.md`):
- Событие: «Сундук чудес снова стучит. Первый раз на неделе — даром.»
- Прогресс: «До чуда: 612 из 700. Или… Домовой знает короткий путь.»
- Фрагмент: «Осколок Эпохи. Кощей уже нервничает.»
- Утешительный: «Не осколок. Зато изба сегодня добрее.»

#### Пул при открытии

**А) Фрагмент (25%, или pity на 8-м)**  
1 фрагмент к **выбранному** locked духу фрагментной очереди, включая Ярилу и Перуна.

**Б) Утешительные (если не фрагмент) — зафиксированный пул:**

| Награда | Что даёт | Примечание |
|---------|----------|------------|
| **Ключ к обычному сундуку** | Обычный сундук (3 ч) сразу готов к открытию | Если уже готов — +1 «запасной» ключ в инвентарь (макс. хранение уточнить в коде) |
| **Ключ к духу** | Открывает квест **Полудницы / Топтыгина / Русалки** | Только если дух ещё locked; иначе реролл в другую строку пула |
| **Эпический титул** | Титул грейда epic из пула титулов | Дубликат → реролл или +2 оберега |
| **Титул Эпохи чудес** | Титул грейда epoch из пула сундука (`tituls.md`) | **Только здесь** (не из обычного сундука 3 ч). Дубликат → реролл или +2 оберега. Квестовые epoch (Лапа Велеса / Славянский Герой / Разгадчик Смерти) в пул не входят |
| **Эпический скин избы** | Скин избы грейда epic | Дубликат → реролл или ключ к обычному сундуку |
| **Тайные обереги ×2** | +2 оберега для викторины | Базовый «приятный» дроп |
| **Сметана** | Полное восстановление энергии | Базовый «приятный» дроп |

Веса утешительных и таблица фрагментов — `dev/loot_tables.md`.

**UI в книге:** у locked — «Собрано 2/5» для Кощея (или текущее `n/m` для выбранной главы) + осколки; выбранный для дропа подсвечен; кот: «Ещё осколок — и Кощей откроется. Если снова смерть не спрячет.»

## 6. Сундук (решение ??? про таймер)

### 6.1. Вердикт по таймеру

**Базовый кулдаун: 3 часа.** Не 4.

| Почему 3 ч | Почему не короче / не длиннее |
|------------|-------------------------------|
| 3–4 сессии в день без ощущения «работы» | 1 ч → выгорание и ощущение фермы |
| Совпадает с обед / вечер / перед сном | 6–8 ч → слишком редко для Яндекс.Игр |
| Rewarded −30 мин даёт смысл смотреть рекламу 1–2 раза | 4 ч без скидки рекламы — слабее монетизация |

**Первое открытие** после Суседко — **сразу готово** (таймер = 0). Дальше — 3 ч от момента открытия.

**Мягкий оффлайн-крючок:** при входе, если сундук готов: кот в сноске — банк `chest_ready` (`cat_dialogs.md`).

### 6.2. Содержимое пула

Скины, титулы, ключи, обереги, сметана, редкие фрагменты.  
**Титулы Эпохи чудес** — только Сундук чудес. Шансы, веса пула 10000, удача +10% rare+ — `dev/loot_tables.md`.

## 7. Системы вовлечения

### 7.1. Кот, энергия, удача

Состояния кота: sit (idle кликабельный) → sleep (бездействие ~45–60 с).

**FX при клике по коту** (`energy > 0`): у точки клика появляется `assets/UI/monete_v1.png`, улетает вверх (~80 px за 0.8 с, fade-out), слой `.layer-fx`. Подробнее — `room_01_layout.md` §7.1.

### 7.2. Суседко ворует монеты (решение ??? скорости)

Только пока кот **спит** и сессия **активна** (оффлайн не наказывается). Тайминги кражи — `dev/technical_requirements.md` §6.

| UX | Поведение |
|----|-----------|
| Предупреждение | «Кажется, кто-то шуршит под половицами…» |
| UI | Монеты с красной обводкой; фразы Суседко (`susedko_dialogs.md`); предупреждение кота |
| Вход в игру | Кот спит → сразу шанс Барабашки (после Суседко и сундука) |
| Прогнать | **5 кликов по Суседко** → исчезновение; дразнилки при каждом клике; энергию не тратит; кот остаётся `sleep` |
| Клик по коту | **не** останавливает кражу |

### 7.3. Жирдяй — смена тона, не наказание

**Принцип дизайна:** Жирдяй — это **ночное событие и смена атмосферы**, а не штраф. Игрок не теряет прогресс, монеты и энергию. Временно режутся механики, чтобы кот «позвал на помощь» — и игрок почувствовал, что ночь в избе другая.

Тайминги, блокировки механик — `dev/technical_requirements.md` §6. Кратко:

| Что блокируется | Клик-кот, сундук, квесты |
| Что НЕ блокируется | Книга, трофеи, настройки |
| Что НЕ теряется | Монеты, энергия, обереги, прогресс |
| Реплики кота | Тег `afraid_night` — смешной страх, не депрессия |
| Как прогнать | Клики по Жирдяю за окном или дождаться рассвета |

**Награда за первого Жирдяя:** титул **«Гроза Жирдяев»** (эпик) + короткая сноска кота: «Мы справились! Я… почти не прятался под лавкой.»

**Почему «вирусный ночной момент»:** неожиданная смена тона (день = кликер, ночь = кот боится) — повод рассказать друзьям («ночью в игре страшно, кот прячется»). Без потери прогресса — только эмоция.

### 7.4. Тайные обереги

При ошибке в викторине: −1 оберег, ответ красный + «Неверно. Сработал тайный оберег», квест продолжается. Источники: старт ×3, сундук, Кикимора, Водяной, «на улице» (пост-MVP: редкий ивент у окна днём).

### 7.5. Викторины

Правила UI и shuffle — `dev/technical_requirements.md` §7. Вопросы и ответы — `quests.md`.  
Провал → `loseMessage` духа + кот. Победа → defeated, награда, трофей, мини-сказ.

## 10. Реклама — только в лоре

**Главное правило:** реклама встроена в мир игры. **Каждый просмотр — только по выбору игрока:** он сам нажимает кнопку и получает награду. Никаких баннеров «СМОТРЕТЬ РЕКЛАМУ», **никакой рекламы на клик по коту** и **никакой принудительной рекламы после викторины**.

### 10.1. Типы рекламы

| Тип | Когда показывается | Лор-обёртка кнопки | Награда |
|-----|-------------------|-------------------|---------|
| **Rewarded** (с наградой) | **Только** если игрок сам нажал кнопку | См. таблицу ниже | По контексту |

**Interstitial (полноэкранная без награды) — не используется.** В том числе после победы в викторине, между вопросами, при открытии книги / сундука, на клик по коту.

**Запрещено:**

- Любая реклама без явного нажатия игроком
- Interstitial в любой точке игры (включая экран победы над духом)
- Реклама на клик по коту
- Реклама при открытии книги / сундука / между вопросами викторины

### 10.2. Rewarded — лор-обёртки

| Точка в игре | Текст кнопки | Награда |
|--------------|--------------|---------|
| Таймер сундука | «Домовой шепчет: поторопи удачу (−30 мин)» | Сундук готов на 30 мин раньше |
| Нет энергии | «Миска сметаны для кота» | +100 энергии (rewarded) |
| Провал викторины (опционально, пост-MVP) | «Тайный оберег из сундука Домового» | +1 оберег (лимит 1/день) |

Кнопки выглядят как элементы избы (миска, свечение сундука, шёпот), не как рекламный баннер.

### 10.3. Тестовый режим

Поведение `isTestMode`, заглушка rewarded — `dev/technical_requirements.md` §9.

### 10.4. Метрики удержания

D1 return (сундук + приветствие), D7 (фрагменты Яги), время до первого сундука &lt; 8 мин, % открывших книгу в первые 60 с.

## 13. Чеклист «сценарий выстрелит»

- [ ] За 90 секунд игрок кликнул кота и открыл книгу  
- [ ] За 5 минут — победа над Домовым и крючок Суседко  
- [ ] За сессию — хотя бы одна коллекционная награда  
- [ ] При уходе — понятно, зачем вернуться (сундук / дух / ночь)  
- [ ] Каждый дух оставляет 1 запоминающуюся деталь  
- [ ] Реклама звучит как помощь духа, не как баннер  
- [ ] Реклама только по кнопке игрока; после викторины — без рекламы  
- [ ] В тестовом режиме rewarded выдаёт награду мгновенно  
- [ ] Провал викторины смешной, не стыдный  
- [ ] Онбординг до сундука укладывается в &lt; 8 мин  
- [ ] В онбординге клики/первые квесты не съедают энергию до нуля  
- [ ] После Суседко открыт только следующий дух очереди (не стена викторин)  
- [ ] Победа над Кощеем даёт и cap +20, и «Разгадчик Смерти»  
- [ ] Можно играть без авторизации; облако — по желанию, не при старте  
- [ ] После входа в Яндекс прогресс подтягивается на другом устройстве
