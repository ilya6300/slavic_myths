## 1. Локация `izba` — композитинг (снизу вверх)

Игрок смотрит **изнутри** избы. Лес и Жирдяй — **снаружи**, видны **через стекло**. Поэтому изба рисуется *поверх* леса и Жирдяя, а стёкла избы должны быть дырками в альфе.

```
камера ─────────────────────────────────────────────────────────
  HUD / стрелки / диалог / модалки          (не в pan)
────────────────────────────────────────────────────────────────
  FX     Монетка при клике, −1 при краже
  1.1.6+ Суседко (только кража, z 55)
  1.1.6  Кот
  1.1.5  Мебель (печка, лавка, сундуки, книга, полки)
  1.1.4  Домовой
  1.1.3  Изба (стены, пол, потолок, наличник, переплёт окна)
  1.1.2  Жирдяй
  1.1.1  Скин леса
────────────────────────────────────────────────────────────────
```

### 1.2. Почему такой порядок (не наоборот)

Старый канон (`hut` z=0, лес поверх в прямоугольнике окна, Жирдяй z=55 поверх мебели) **отменяется**.

Жирдяй (`fatso.png`) — поясной портрет, ладони к зрителю. Он должен **упираться в стекло с улицы**: переплёт и наличник избы лежат *на нём*, лес — *за ним*. Если Жирдяй выше избы, он «висит в комнате». Если лес выше избы — пропадает рама окна.

### 1.3. Жёсткое требование к ассету избы

Все скины `assets/house/hut_*.png`:

| Зона PNG | Альфа | Зачем |
|----------|-------|-------|
| Стены, пол, потолок, наличник, импост (крест переплёта) | непрозрачная | держит интерьер |
| **Стёкла / проёмы окна** | **α = 0** | лес и Жирдяй видны «в окне» |
| Вне сруба (если есть поля) | α = 0 | не маскировать лес зря |

**Сейчас** у `hut_standart.png` / `hut_rate.png` / `hut_epic.png` / `hut_the_age_of_miracles.png` проём окна залит **чёрным**. Это ломает канон 1.1.1→1.1.3. Правка арта — **P0** (вырезать альфу стёкол, чёрный не оставлять).

Пока альфы нет — **временный fallback** (не канон):

1. Изба как непрозрачный фон.
2. В прямоугольнике окна (координаты `sceneLayout.ts` / `room_01_layout.md` §4) поверх чёрного рисуются `.layer-forest` и `.layer-fatso` с `clip-path` / overflow hidden.
3. Порядок внутри клипа всё равно: лес → Жирдяй.
4. Наличник не перекрывает Жирдяя (ограничение fallback).

Как только стёкла вырезаны — fallback удалить, вернуть полный стек §1.1.

### 1.6.1. Камера и кадрирование (широкоформат)

Скин избы **не** 16:9 — пропорции арта уже, чем типичный widescreen. Viewport устройства задаёт «окно»; inner **центрируется** так, чтобы в кадре комнаты 1 всегда оставались три якоря:

| Якорь | Эталон (room_01 §5) | Зачем |
|-------|---------------------|-------|
| **Окно** | проём ~`left 38%`, `top 22%` | лес, Жирдяй, ночь |
| **Кот** | `left 32%`, `bottom 8%` | главный клик |
| **Книга** | `left 70%`, `bottom 2%` | бестиарий |

**Правило:** вычислить bounding-box якорей + отступ **4%** сцены по краям; сместить inner по X (и при необходимости Y), пока bbox целиком в viewport. На ultra-wide края (печка слева, сундуки справа) могут обрезаться — якоря **нет**.

| Ориентация | Поведение камеры |
|------------|------------------|
| Landscape / desktop | Центрирование по safe-frame; pan по X **только** если inner шире viewport и игрок тянет жестом / стрелками комнат |
| Portrait (телефон), комната 1 | Горизонтальный scroll / swipe; scroll-snap — `room_01_layout.md` §9 |
| Portrait (телефон), комната 2 | Горизонтальный scroll / swipe; scroll-snap по ярусам полок — `room_02_trophies_layout.md` §1 |
| Книга / модалка открыта | pan и scroll сцены **выключены** |

`object-fit` фона избы: `cover` внутри inner без непропорционального растягивания по одной оси. HUD, стрелки навигации — `position: fixed`, не участвуют в pan.

| Кто | Где | Видимость | Ассет | Позиция |
|-----|-----|-----------|-------|---------|
| **Домовой** | **только комната 1** (хаб) | после `brownieDefeated` | активный скин `assets/brownie/…` | см. §1.7.1 |
| Суседко (кража) | комната 1, `susedkoStealActive` | только во время кражи | `assets/enemy/susedko.png` | пул статичных позиций §1.7.2; слой `.layer-susedko-steal` **55** |

В комнате трофеев Домовой **не рендерится** (его «награда» — жить в избе, не трофей на полке).

Слой Домового (1.1.4) **ниже** мебели. **Исключение:** Суседко при краже — отдельный слой **55**, **выше** мебели и кота, чтобы его не перекрывали интерьер и кот. Домовой не кликается; Суседко при краже — кликабелен.

#### 1.7.1. Респавн Домового (комната 1)

При **каждом входе** в комнату 1 (`setIzbaRoom(1)`, первый заход в сессию, возврат из трофеев) — новая поза из пула. Координаты фиксируются до следующего выхода из комнаты 1.

**Допустимые зоны** (примеры, не исчерпывающий список — расширять в `sceneLayout.ts`):

| ID зоны | Описание | Пример координат |
|---------|----------|------------------|
| `stove_peek` | Выглядывает из печки; печка (1.1.5) может перекрыть ноги | `left 4%`, `bottom 18%`, `width 8%` |
| `bench_under` | Сидит под скамейкой, видна голова / плечи | `left 28%`, `bottom 20%`, `width 7%` |
| `floor_left` | Открытый пол у печки | `left 10%`, `bottom 10%`, `width 9%` |
| `floor_center` | Пол между скамейкой и котом | `left 22%`, `bottom 8%`, `width 8%` |
| `floor_window` | У окна, на полу | `left 42%`, `bottom 12%`, `width 8%` |

**Валидация перед выбором:**

1. Bounding-box Домового **не пересекается** с hit-box кота (запас **2%** сцены по X/Y).
2. Спрайт **виден игроку** — не полностью за непрозрачной мебелью; «выглядывание» из печки / из-под лавки допустимо (частичное перекрытие края печки или скамейки).
3. Точка на **полу** inner комнаты 1 (`bottom` > 0), не в зоне трофеев (правая половина inner).

Алгоритм: случайный выбор из пула → проверка → при провале до **5** попыток → fallback `stove_peek`.

#### 1.7.2. Позиции Суседко при краже (комната 1)

При старте кражи (`susedkoStealActive = true`) — **одна** случайная позиция из пула. Позиция **фиксирована** до конца события (прогнали или stop-loss по монетам). Координаты — % от inner комнаты 1, якорь `bottom center`, hit-area ≥ 44×44 px.

| ID | Описание | `left` | `bottom` | `width` |
|----|----------|--------|----------|---------|
| `after_stove` | Пол справа от печки (не на печке) | `24vw` | `7vh` | натуральный PNG |
| `under_bench` | У скамейки | `33vw` | `12vh` | натуральный PNG |
| `floor_center` | Между скамейкой и окном | `44vw` | `8vh` | натуральный PNG |
| `window_corner` | У окна | `55vw` | `10vh` | натуральный PNG |
| `near_chest` | У сундука | `63vw` | `11vh` | натуральный PNG |

**Правила:**

1. Суседко **не** стоит на печке и не перекрывает кота (z **55** — только чтобы его было видно поверх мебели).
2. Спрайт полностью в кадре комнаты 1 (левая половина inner); **без `width`** на контейнере — натуральный PNG, `max-height: 16vh`.
3. При старте кражи — случайная позиция из пула; **при каждом клике** — другая случайная позиция (не та же).

Реплики при клике — `instruction/susedko_dialogs.md`.

### 1.8. Мебель (1.1.5)

Печка, скамейка, сундуки, подставка, книга, полки, трофеи — все здесь. Координаты по-прежнему в `room_01_layout.md` / `room_02_trophies_layout.md` → `sceneLayout.ts`.

Книга и сундуки интерактивны; печка и лавка — нет.

### 1.9. Кот (1.1.6)

Всегда **перед** мебелью. Спрайт активного скина (`sit` / `sleep` / …). Клик не перехватывается Жирдяем, если Жирдяй скрыт; если Жирдяй на экране — приоритет hit-test: Жирдяй (окно) > кот.

## 2. Две комнаты и переход

Одна сцена `.izba-scene__inner { width: 200%; }`. Камера:

| Viewport | Класс | `translateX` | В кадре |
|----------|-------|--------------|---------|
| Комната 1 — хаб | `.room--01` | `0` | кот, книга, сундуки, печка, окно |
| Комната 2 — трофеи | `.room--02` | `-50%` | полки, трофеи; окно — если ещё в кадре слева |

Длительность pan: **0.35 s**, `ease-out`. Не fade, не смена `src` фона.

### 2.1. Стрелки по наведению на край

Стрелки **не** висят постоянно на десктопе.

| Зона | Класс | Когда видна | Действие |
|------|-------|-------------|----------|
| Правые **8%** viewport | `.izba-edge--right` | hover (pointer fine) **и** камера в комнате 1 | показать `arrow_right_wood.png`, клик → комната 2 |
| Левые **8%** viewport | `.izba-edge--left` | hover **и** камера в комнате 2 | показать `arrow_left_wood.png`, клик → комната 1 |

| Параметр | Значение |
|----------|----------|
| Появление стрелки | opacity 0→1 за 0.18 s после входа в зону |
| Исчезновение | 0.15 s после ухода |
| Размер кнопки | min **56×56 px**, `top: 50%`, `translateY(-50%)` |
| z-index | `80` (`.layer-nav`), `position: fixed` к viewport, не к inner |
| Touch (грубый указатель) | стрелки **всегда** полупрозрачные `opacity: 0.55` на нужном крае; тап = переход |
| `aria-label` | «Комната трофеев» / «Вернуться в избу» |

Зоны края **не** перекрывают аватар HUD слева сверху: hit-area стрелки по вертикали — средние 60% высоты (`top: 20%; height: 60%`), не весь столбец 8%.

### 2.2. Свайп / drag

Работает **и** на таче, **и** на мыши (drag по сцене).

| Параметр | Значение |
|----------|----------|
| Слушатель | `.izba-scene` (не HUD, не модалка, не диалог) |
| Ось | только X |
| Порог смещения | **18%** ширины viewport **или** флик > 0.45 px/ms |
| Во время жеста | inner следует за пальцем с rubber-band на краях |
| Отпуск ниже порога | snap назад в текущую комнату, 0.2 s |
| Отпуск выше порога | snap в соседнюю, 0.35 s |
| Конфликт с кликом кота | если `abs(dx) < 12 px` и `dt < 300 ms` — это клик, не свайп |
| Модалка / профиль / книга открыты | жесты сцены **выключены** |

Стрелка и свайп — два входа в **один** action `setIzbaRoom(1 | 2)`.

## 5. Инварианты для разработки
