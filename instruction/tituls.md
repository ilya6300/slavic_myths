# Титулы кота

> Источник правды для UI (бейдж у кота) и пула сундука.  
> Согласовано с `scenario.md` §5.4 / §7.3 и наградами в `list_of_spirits.md`.  
> **Зачем титул игроку:** короткая гордость + повод открыть сундук / добить квест.  
> **Правило источников:** часть титулов — только квест/событие (заслуга), часть — сундук (коллекция и FOMO). Дубликат из сундука → реролл или обереги (см. scenario).

**Поля:** название · грейд · источник · описание для UI (1 фраза, голос мира) · заметка для ТЗ (не на экран, если пусто).

## Сводка по источникам (для баланса сундука)

| Источник | Сколько титулов | Зачем |
|----------|-----------------|--------|
| Старт | 1 | Ясный бейдж с первой секунды |
| Только квест / ночь | 16 | Прогресс ощущается «заслуженным» |
| Обычный сундук (3 ч) ordinary | 6 | Частый дроп, шутки, коллекция |
| Обычный сундук (3 ч) rare | 6 | Возврат к таймеру 3 ч |
| Обычный сундук (3 ч) / Сундук чудес epic | 3 | Редкость mid-game |
| **Сундук чудес** epoch | 6 | Еженедельный FOMO; не из 3-часового сундука |

**Не класть в сундуки:** все квестовые и «Гроза Жирдяев» — иначе обесценивается победа над духом / ночью.  
**Не класть в обычный сундук (3 ч):** титулы Эпохи чудес — только Сундук чудес.

## Что улучшили относительно старого списка

1. **Грейд:** «Лапа Велеса» перенесена в Эпоху чудес (как в §5.4), не epic.
2. **Дыры §5.5 закрыты:** «Полевой кот», награда Кощея = cap +20 и «Разгадчик Смерти» (оба).
3. **Квест ≠ только сундук:** титулы за Домового, Суседко, Банника, Кикимору, лесных и эпиков — повод идти в книгу, а не только кликать таймер.
4. **Меньше канцелярита:** «Избушки Защитник» → «Защитник Избы»; живые описания под бейдж/модалку.
5. **Опечатки:** «Эпоха чудем», хвост `сундукs` — убраны.
6. **Повтор «Страж/Охотник»** разбавлен бытовым и фольклорным юмором (Тапочный Воин, Распутыватель Ниток, Береговой).
