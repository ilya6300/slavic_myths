## 1. UX-решение

### Что видит игрок

**Фон локации** берётся из поля духа `Локация квеста` (`list_of_spirits.md`) → ID в таблице §5. Не назначать фон в лейауте «на глаз». Правило: `izba_scene_layers.md` §3.

| Этап | Что на экране | Тапов до действия |
|------|---------------|-------------------|
| Старт | Фон локации + заголовок духа + «Вопрос 1 из N» | 0 (уже в квесте) |
| Вопрос | Текст вопроса + 2–3 кнопки ответа | 1 |
| Верно | Кнопка зеленеет 0.4 с → следующий вопрос | 0 (авто) |
| Ошибка + оберег | Красный ответ + подпись оберега → тот же вопрос продолжается | 0 |
| Победа | Экран награды + мини-сказ | 1 «Забрать» |
| Провал (0 оберегов) | `loseMessage` духа + реплика кота | 1 «В избу» |

**Энергия:** −10 при старте квеста (кроме онбординга Домовой/Суседко — §4.2 `scenario.md`).

**Реклама:** после викторины **нет** (§10 `scenario.md`).

## 3. Слои и z-index внутри викторины

| Слой | z-index | Содержимое |
|------|---------|------------|
| Фон локации | `0` | JPEG/PNG + затемняющий overlay `rgba(20, 15, 10, 0.35)` |
| Панель вопроса | `10` | Деревянная карточка по центру |
| Портрет духа | `15` | Гравюра `creatures_in_the_book/` |
| FX | `20` | Вспышка верного/неверного, −1 оберег |
| HUD | `30` | Энергия + счётчик оберегов (компактно) |

## 4. Размеры и отступы

### 4.1. Панель вопроса (`.quiz-panel`)

| Свойство | Desktop | Mobile |
|----------|---------|--------|
| `width` | `min(92%, 560px)` | `94%` |
| `max-height` | `70vh` | `78vh` |
| `padding` | `20px 24px` | `16px` |
| Позиция | `center` (flex) | то же |
| Фон | деревянная текстура PNG nine-slice *(нужен ассет)* | то же |
| Fallback CSS | `background: linear-gradient(180deg, #6b4a2e, #4a3220)` + `border-radius: 12px` + `box-shadow: 0 8px 32px rgba(0,0,0,0.45)` | то же |

### 4.2. Шапка (`.quiz-header`)

| Элемент | Стиль |
|---------|-------|
| Имя духа | 20px, `#f5e6d0`, font-weight 600 |
| Прогресс | «Вопрос **2** из **5**» — 14px, `#c9a87c` |
| Точки прогресса | `●○○○○` — заполненные = пройденные вопросы в текущей попытке |
| Грейд-бейдж | common / rare / epic / epoch — цвета как в книге |

### 4.3. Текст вопроса (`.quiz-question`)

| Свойство | Значение |
|----------|----------|
| Размер | 17–18px (mobile 16px) |
| Цвет | `#fff8ee` |
| line-height | 1.45 |
| max-lines | 5 (дальше — scroll внутри панели) |

### 4.4. Кнопки ответов (`.quiz-answer`)

| Свойство | Значение |
|----------|----------|
| Количество | 2 или 3 (из `quests.md`) |
| Высота | min **52px** (touch 48px+) |
| Отступ между | `12px` |
| Стиль | деревянные плашки, carved edge |
| Текст | 15–16px, по центру, **без** префиксов А/Б/В |
| Состояние `default` | `#e8d4b8` текст на `#5c3d28` |
| Состояние `correct` | фон `#4a7c59`, текст белый, 0.4s |
| Состояние `wrong` | фон `#8b3a3a`, подпись «Неверно. Сработал тайный оберег» 13px |
| Состояние `disabled` | после выбора — остальные `opacity: 0.5` |

## 6. Экраны результата

### 6.1. Победа (`.quiz-result--win`)

```
┌─────────────────────────────────────┐
│         ✓ Победа!                   │
│   [иллюстрация духа — гравюра]      │
│   Награда: +5 макс. энергии         │
│   [мини-сказ кота — 2 строки]       │
│   [ Забрать награду ]               │
└─────────────────────────────────────┘
```

- Без рекламы, без interstitial.
- Пауза 0.6 с на анимации «оживания» гравюры (лёгкий scale pulse).
- Кнопка «Забрать» → закрыть викторину, обновить книгу/трофей/избу.

### 6.2. Провал (`.quiz-result--lose`)

- Заголовок: имя духа остаётся `available`.
- Текст: `loseMessage` из `list_of_spirits.md`.
- Реплика кота снизу (мини-сноска, не полноэкранный VN).
- Одна кнопка: «В избу».

## 7. Обереги в UI

| Место | Отображение |
|-------|-------------|
| HUD викторины | Иконка щита + число `🛡 3` (PNG, не emoji в проде) |
| При ошибке | −1 анимация: щит трескается, число уменьшается |
| 0 оберегов + ошибка | Провал квеста (не бесконечные попытки) |

## 9. Анимации

| Событие | Длительность | Easing |
|---------|--------------|--------|
| Открытие викторины | 0.3s fade + scale panel 0.95→1 | ease-out |
| Верный ответ | 0.4s зелёный flash | — |
| Неверный + оберег | 0.5s красный + shake панели 2px | — |
| Следующий вопрос | crossfade текста 0.25s | — |
| Победа | confetti из «чернил» (CSS particles), 1s | — |
