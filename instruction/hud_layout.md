## Решение игрока (обязательно)

### Шапка HUD — ресурсы и «кто я»

- **Решение сейчас:** могу ли кликать / открыть сундук / идти в путь; сколько монет и оберегов на следующий тап; хватит ли **пучков** на оберег / идти ли во двор; кто я (профиль).
- **Без каких данных нельзя решить:** `energy/maxEnergy`; `luckCoins`; `talismans`; `yardGrass` / cap 3; морда + титул.
- **Где живёт:** HUD (взгляд). Энергия — **центр шапки**. Монеты, обереги, **трава**, сметана — **правый верх**. Профиль — **левый верх**.
- **Что НЕ показывать здесь:** прогресс сундука чудес (он на **полу** под эпиком, `room_01_layout.md` §4.4.1); regen/сек; бонусы скинов; IAP; Кикимора; «Ларец»; сметана, если `smetanaCount === 0`; трава, если онбординг не завершён (двора ещё нет).
- **Худший кадр:** ночь + лес + кража Суседко + pan street→1→2 + титул en/tr + чип `3/3` + оба слота рельса. Чипы — тёмное стекло, не золотая обводка.

### Рельс слева — события, не инвентарь

- **Решение сейчас (дар):** взять стартовый дар или закрыть. Без спрайта ларца и двух слов подписи нельзя понять, что это не сундук в избе.
- **Решение сейчас (Кикимора):** открыть тканьё оберега **сегодня**. Сколько пучков — **не** на ней: это чип травы в шапке. Без спрайта персонажа нельзя понять, кто плетёт.
- **Где живёт:** `.hud-rail` — не шапка. На улице рельс Кикиморы скрыт; чип травы в шапке **остаётся** (сбор).
- **Что НЕ показывать здесь:** энергию, монеты, титул, гравюру из книги, второе число `n/3`.
- **Худший кадр:** тот же + «Wanderer's gift»; Кикимора без цифры не путается с чипом травы.

## Layout vs mockup (обязательно)

Mockup PNG не генерируется (gate `spec_only`). Таблица — закон вёрстки для разработчика.

| Зона | Выравнивание | Ширина / object-fit | CSS-классы |
|------|----------------|---------------------|------------|
| Шапка `.hud-top` | space-between; энергия **абсолютно по центру viewport** | 100vw; padding safe-area | `.layer-hud` → `.hud-top` |
| Профиль | left; морда + титул в один ряд | аватар 48×48 (моб.) / 56×56 (десктоп); титул `max 18ch` ellipsis | `.hud-profile` |
| Энергия | центр экрана (`left: 50%; transform: translateX(-50%)`) | чип по контенту; иконка 32×32, `contain` | `.hud-energy` (не внутри `.hud-resources`) |
| Монеты + оберег + **трава** + сметана | right, **inset** `padding-right: max(16px, 5vw)` на `.hud-top`; `margin-left: auto` на кластере; не у физического края | иконка 32×32 `contain`; трава `n/3`; `max-width: min(46vw, 300px)` — не наезжать на энергию | `.hud-resources` |
| Рельс | колонка **под** профилем, `left: 8px` | спрайты натуральный PNG, **без** `width: 100%` | `.hud-rail` |
| Дар путника | спрайт ларца по центру слота; подпись под ним, `text-align: center` | ларец `max-height: 64px` (`56px` моб.), `object-fit: contain`; подпись `max 16ch` | `.hud-rail__offer` |
| Кикимора | силуэт bust по центру слота; подпись «Сплести» / имя, **без** `n/3` | спрайт `max-height: 88px` (`72px` моб.), `contain`; **не** `cover` в круге | `.hud-rail__kikimora` |
| CTA модалки «Оплатить» | центр панели; **не** stretch 100% колонки | `book_quest_btn_wood.png` `contain`; `max-width: 280px`; `margin: 0 auto` | `.starter-pack-modal__pay` |

## Не путать

- центр энергии в шапке ≠ центр рельса
- полёт / pan камеры ≠ выравнивание HUD
- «ларец» как предмет в модалке ≠ текстовая кнопка «Ларец» в шапке
- пучок на дворе (диегетик) ≠ чип травы в шапке (инвентарь)
- `n/3` на чипе травы ≠ подпись у Кикиморы (цифру не дублировать)

## 2. UX успешной казуальной игры (закон раскладки)

Как Hay Day / Gardenscapes / сильные кликеры: **шапка = взгляд (ресурсы + я)**. **Левый край = события и персонажи**. **Сцена = действие**. Не мешать три плотности.

```
┌─────────────────────────────────────────────────────────────────┐
│ [🐱 Новенький]          [⚡ 87/120]        [🪙 142] [🛡 3] [🌿 2/3] │  ← шапка
│                                                                 │
│ [🎁 ларец PNG]                                                  │  ← рельс
│  Дар путника                                                    │
│ [🧶 Кикимора bust]                                              │
│  Сплести                                                        │
│                                                                 │
│              сцена: кот · сундук · книга                        │
│              [сноска кота]                                      │
└─────────────────────────────────────────────────────────────────┘
```

| Семья | Что | Плотность |
|-------|-----|-----------|
| Шапка | профиль, энергия, монеты, оберег, **трава**, сметана | минимум; тёмное стекло |
| Рельс | дар (пока не куплен), Кикимора (пока дух побеждён) | спрайт + 1 строка |
| Сцена | кот, сундук, книга, двор | диегетик |
| Меню | модалка дара, модалка крафта | можно читать; вход ≤ 0.28s |

**Тапы:** рельс (1) → модалка (1 CTA). Закрыть: × или затемнение. От избы до крафта **без** обязательного pan на улицу.

## 3. Визуальный язык HUD — современный, не «фанера»

Дерево в этой игре — **PNG** (`book_quest_btn_wood.png`, мебель, обложка книги). Не `border: 2px solid #8b6914`.

| Где | Материал | Запрещено |
|-----|----------|-----------|
| Чипы шапки | `rgba(40, 28, 18, 0.72)` + `backdrop-filter: blur(4px)`; без рамки | градиент «доски», золотой CSS-бордер, резной орнамент из box-shadow |
| Рельс | спрайт на прозрачном; подпись на той же плашке, что чипы шапки, **только под текстом** | круг-кроп, обводка `#8b6914`, деревянный планшет на весь слот |
| CTA в модалках | `assets/UI/book_quest_btn_wood.png` + текст поверх | жёлтый `#f0c14a` прямоугольник на 100% ширины |
| Панель модалки | как `.cat-dialog`: тёмное стекло, без CSS-золота | `border: 2px solid #8b6914; border-radius: 16px` как единственный «стиль дерева» |

**Второй сигнал состояния** (цвет не один):

| Состояние | Цвет | Второй сигнал |
|-----------|------|----------------|
| Энергия 0 | число не «просто красное» | пульс чипа + иконка энергии |
| Кража монет | красная обводка (уже есть) | пульс `.hud-coins--stealing` |
| Дар доступен | тёплый блик на ларце | медленный `scale 1.00↔1.04` 2.4s |
| Кикимора готова (`grass ≥ 3` и не крафтили сегодня) | лёгкое тепло на пряже | bounce 1.2s + подпись «Сплести» |
| Кикимора ждёт траву | спокойный idle | без числа (число на чипе) |
| Уже сплели сегодня | без пульса | тап открывает модалку с «Сегодня уже сплели» |
| Сбор пучка | — | пучок пропадает; чип `.hud-grass` тикает `n`→`n+1`, вспышка |
| Cap 3, тап по пучку | чип `.hud-grass--full` | отказ: лёгкий shake чипа, пучок остаётся |
| Крафт 3→1 оберег | трава `3/3`→`0/3`, оберег +1 | оба чипа тикают |

Juice на тап рельса: `scale(0.97)` 120ms. Смена числа в шапке — тик, не молчаливый прыжок.

## 4. Шапка — позиции

Safe-area: `top/left/right: max(8px, env(safe-area-inset-*))`. `.layer-hud` `pointer-events: none`; кликабельные дети — `auto`.

| ID | Класс | Позиция | Поведение |
|----|-------|---------|-----------|
| profile | `.hud-profile` | top-left | как `profile_layout.md`; **не** оборачивать в стек с Кикиморой |
| energy | `.hud-energy` | **центр шапки**, не в `.hud-resources` | `текущая/макс`; при 0 — пульс |
| coins | `.hud-coins` | правый кластер | число; при краже — `--stealing` |
| oberegs | `.hud-oberegs` | правый кластер | иконка + число |
| grass | `.hud-grass` | правый кластер, после оберега | **`n/3`**; см. §4.1 |
| smetana | `.hud-smetana` | в правом кластере, только если count > 0 | тап → подтверждение |
| miracle | — | **убрать из шапки** | прогресс — **бар с заливкой на полу** под сундуком чудес (`room_01_layout.md` §4.4.1); не чип HUD и не голый `0/700` |

Иконки 32×32 PNG, hit-area ≥ 44×44 **отдельным слоем**, не растягивая PNG.

### 4.1. Трава — ресурс, не подпись у NPC

`yardGrass` (cap `YARD_GRASS_CAP` = 3) — ингредиент оберега: три пучка → один оберег, лимит 1/сутки. Это **ресурс инвентаря**, как оберег, а не «цифра на персонаже».

| Правило | Как |
|---------|-----|
| Где число | только `.hud-grass` в шапке, формат **`n/3`** (тот же паттерн, что энергия `n/max`) |
| Где пучок | двор: диегетик `.yard-grass`; модалка крафта: слоты (уже есть) |
| Где не число | рельс Кикиморы — **запрещено** дублировать `n/3` |
| Видимость чипа | `onboardingCompleted` (двор открыт). До онбординга чипа нет |
| Иконка | `assets/ui/icon_grass.png` (P1); fallback `assets/furniture/yard_grass.png`, 32×32 `contain` |
| Клик | не открывает крафт (это делает Кикимора). Tooltip: «Три пучка — Кикимора сплетёт оберег» |
| Порядок в кластере | монеты → оберег → **трава** → сметана (трава **тратится в оберег**, стоит рядом) |

Сбор на улице: шапка не в pan — чип **виден**, пока Кикимора на рельсе скрыта. Тап по пучку → `collectYardGrass` → число тикает, чип вспыхивает. При `n === 3` класс `.hud-grass--full`; повторный сбор не проходит — shake чипа, пучок не исчезает.

Крафт: `3 → 0` на чипе травы и `обереги +1` одновременно. Если Кикимора ещё не побеждена, пучки всё равно копятся (домен так устроен); чип учит ресурс, крафт закрыт репликой `yard_need_kikimora`.

## 5. Дар путника (вместо кнопки «Ларец»)

### 5.1. Имя

| Язык | Подпись рельса / заголовок модалки | Почему |
|------|-------------------------------------|--------|
| ru | **Дар путника** | фольклорно; рифмуется со скином `cat_pilgrim`; это **дар**, не SKU |
| en | Wanderer's gift | ≤ 16ch |
| tr | Yolcunun armağanı | проверить ellipsis, `max 16ch` |

**Не использовать**

- «Пак новичка» / starter pack — англицизм, из другой игры.
- «Ларец» одним словом — пусто, как чит-кнопка.
- «Ларец новичка» в HUD — магазинный ярлык; в лоре модалки ларец **можно** назвать предметом («Домовой принёс ларец»).

Копирайт модалки (ru / en / tr):

| Ключ | ru | en | tr |
|------|----|----|----|
| title | Дар путника | Wanderer's gift | Yolcunun armağanı |
| lore | Домовой принёс ларец страннику. | The Domovoy brought a casket for the wanderer. | Domovoy yolcuya bir sandık getirdi. |
| owned | Дар уже твой | The gift is already yours | Armağan zaten senin |
| later | Не сейчас | Not now | Şimdi değil |

Ключ `starterPackHud` («Ларец») **удалить** — в HUD нет текста-кнопки.

### 5.2. Элемент рельса

Не кнопка-лейбл. Это **предмет**: `assets/furniture/starter_casket.png`.

```
┌─────────────┐
│   [ларец]   │  max-height 64px, contain, α как в PNG
│ Дар путника │  12px, #f5e6d0, center, max 16ch
└─────────────┘
hit ::before ≥ 56×56, PNG не растягивать
```

| Состояние | Видно | Поведение |
|-----------|-------|-----------|
| Оффер (`isStarterPackOfferVisible`) | да | тап → модалка; shimmer + pulse |
| Куплен / оффер скрыт | нет (слот схлопывается) | — |

Модалка: тёмное стекло как диалог кота; ларец крупно по центру (`max-width: 45%`, `contain`); три награды в ряд (энергия, оберег, кот-путник); CTA «Оплатить {price} ₽» на деревянном PNG, **не** `width: 100%`; «Не сейчас» текстовая ссылка под CTA, не вторая деревянная дверь.

## 6. Кикимора — отдельный спрайт-компаньон

В шапку и под морду кота **не влезает**: другой смысл (крафт, не «кто я»), другой масштаб, гравюра ломает пластилин HUD.

Она живёт **на рельсе** как персонаж, который предлагает услугу. Как продавец у края экрана в казуальных фермах: лицо читается, подпись одна, тап открывает её дело.

### 6.1. Где и где не

| Место | Вердикт |
|-------|---------|
| `.hud-profile-stack` под котом | **запрещено** |
| Круг 44px + гравюра книги | **запрещено** |
| Сцена избы (печка / угол) | нет: перекроет кот/сундук, сломает эталон комнаты 1 |
| Двор как второй персонаж мира | нет в этом эпике: двор = трава; крафт = модалка |
| `.hud-rail` на избе (комнаты 1 и 2) | **да** |
| Улица | рельс Кикиморы **спрятан**; чип `.hud-grass` в шапке **виден** — игрок считает пучки |

Показ: `isKikimoraCraftAvailable()` (дух побеждён). Иначе слота нет.

### 6.2. Спрайт

**Канон:** `assets/ui/kikimora_companion.png` — поясной 3D-bust, пряжа в руках, прозрачный фон. Промпт: `design_assets_prompts.md`.

**Пока файла нет (MVP-fallback):** `assets/furniture/kikimora_weaving.png`, кроп bust (`object-fit: cover; object-position: 50% 12%`) в слоте **без** `border-radius: 50%` и без гравюры.

**Никогда:** `assets/creatures_in_the_book/kikimora.png` в HUD.

### 6.3. Слот

```
┌──────────────┐
│ [bust PNG]   │  max-height 88px / 72px моб., contain
│ Сплести      │  только если можно крафтить; иначе имя «Кикимора»
└──────────────┘
```

| Состояние | Подпись | Motion |
|-----------|---------|--------|
| 0–2 пучка, лимит дня не исчерпан | **Кикимора** | idle |
| 3 пучка, сегодня ещё не ткали | **Сплести** | bounce + лёгкий glow пряжи |
| Сегодня уже сплели | **Кикимора** | idle, без bounce |
| Модалка открыта | без доп. «вдавливания» | — |

`aria-label`: «Кикимора — сплести оберег». Сколько пучков — **только** на `.hud-grass`, не второй раз здесь.

Модалка крафта: слоты пучков + `{n} / 3` внутри меню (игрок уже остановился — можно плотнее). Оболочка — тёмное стекло как диалог, CTA на `book_quest_btn_wood.png`, не CSS-золото.

      <span class="hud-stat hud-coins">…</span>

  <aside class="hud-rail" aria-label="События">
