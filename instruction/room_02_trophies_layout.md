## 1. UX-решение

### Что видит игрок

Вторая комната — **та же изба**, камера сдвинута вправо (pan). На боковых стенах **слева и справа от окна** — лаконичные настенные полки с трофеями. Одна задача: **осмотреть коллекцию** и прочитать мини-сказ по клику.

| Элемент | Интерактив | Приоритет |
|---------|------------|-----------|
| Трофей (получен) | Да — модалка «Сказ о победе» | **Главный** |
| Пустой слот | Да — «Ещё не встречен» | Средний |
| Стрелка «← Изба» | Да — комната 1 | Высокий |
| Полки, лавка, стены | Нет | Декор |

**Домовой** в комнате трофеев **не рендерится** — 15 слотов (все духи кроме Домового).  
**Фон** — тот же скин `assets/house/` + лес в окне (`izba_scene_layers.md`). Отдельного `trophy_room_bg` **нет**.

### Компоновка (вид 16:9, эталон Ильи)

```
┌────────────────────────────────────────────────────────────────┐
│ [←]                                                            │
│         [□ □]        ╭── окно ──╮        [□ □ □]               │
│         [□ □]        │  лес     │        [□ □ □]               │
│         [□ □]        ╰──────────╯        [□ □ □]               │
│                                                                │
│              [ лавка — декор, 35vw / 75vh ]                    │
└────────────────────────────────────────────────────────────────┘
     ↑ 30vw, 40/50/60vh              ↑ 57vw, 40/50/60vh
```

- **Окно** — центр кадра (`windowAperture` в `sceneLayout.ts`).
- **Полки** — по **3** с каждой стороны от окна; якорь `left` + `top` (§3.2).
- **4-й ярус слева** — не полка, а **лавка** (`bench.png`), декор.

### Принцип плотности

| Правило | Значение |
|---------|----------|
| Полок всего | **6** (3 слева + 3 справа) |
| Лавок (декор) | **1** (слева внизу; см. §3.6) |
| Трофеев на полку | **2** (слева), **3** (справа); **макс. 3** |
| Всего слотов | **15** |
| Размер полки на экране | **11 vw** ширина |
| Размер трофея | **фиксированный** `3.8 vh` по высоте |
| Зазор между трофеями | ≥ **12%** ширины полки между центрами соседних слотов |

### Расширение коллекции (будущие духи)

Новые слоты трофеев — **только за счёт дополнительных лавок** (`bench.png`), не новых полок и не увеличения размера комнаты:

| Правило | Как |
|---------|-----|
| Куда ставить | Нижняя зона комнаты 2, `top` ≥ `75 vh`, вне зоны окна |
| Ассет | `assets/furniture/bench.png`, `width: 14 vw` |
| Трофеи на лавке | До **3** шт., те же `3.8 vh` и классы слотов, что на полке |
| Координаты | Новая лавка — новая запись в `room2Benches[]` (`sceneLayout.ts`) + класс в CSS |

Полки **не плодить** без отдельного решения геймдизайнера — текущая сетка 3+3 закрывает 15 духов.

## 2. Система координат

**Единицы:** только **`vw` / `vh`** от `.izba-room--2` (комната = `100vw`). Как комната 1 (`index.css`).

| Ось | Правило |
|-----|---------|
| Полка | `position: absolute`; `left` + `top` — **левый верхний угол** контейнера `.room-shelf` |
| Трофей на полке | `bottom: 88%` от полки; горизонталь — `%` от ширины полки (см. §3.3) |
| Лавка | `left`, `top`, `width` в `vw`/`vh` |

Стек DOM и z-index — **`izba_scene_layers.md` §1.1**. Комната 2 не вводит свои z-index.

**Канон в коде:** позиции полок — `trophyWallShelves` в `sceneLayout.ts`; пиксели на экране — `index.css` §«Комната 2».

> ⚠️ **Устарело (v1.3):** «правая половина inner», `left ≥ 50%`, сетка 3×5, `width: 84%` полки — **не использовать**.

## 3. Сетка полок и слотов

### 3.1. Настенная полка (повторяемый ассет)

| Свойство | Значение | Примечание |
|----------|----------|------------|
| Класс | `.room-shelf` | контейнер + `__img` + `__slots` |
| Ширина на экране | **`11 vw`** | **обязательно** — исходник `shelf.png` 1024×1024, без scale ломает сцену |
| Высота | `auto` от ассета | `width: 100%` на `__img` |
| Ассет | `assets/furniture/shelf.png` | целевой исходник **≈ 280×72 px** (горизонтальная доска) — см. `design_assets_prompts.md` |
| z-index | `40` | `.layer-furniture` |

### 3.2. Позиции полок (`trophyWallShelves`)

| ID | Сторона | `leftVw` | `topVh` | Слотов |
|----|---------|----------|---------|--------|
| `wall-l-1` | левая | `30` | `40` | 2 |
| `wall-l-2` | левая | `30` | `50` | 2 |
| `wall-l-3` | левая | `30` | `60` | 2 |
| `wall-r-1` | правая | `57` | `40` | 3 |
| `wall-r-2` | правая | `57` | `50` | 3 |
| `wall-r-3` | правая | `57` | `60` | 3 |

Шаг по вертикали: **10 vh** (`40` → `50` → `60`). Горизонталь: левая колонка `30 vw`, правая `57 vw`.

**4-й ярус слева** — лавка, не полка (§3.6).

### 3.3. Слоты трофеев на полке

Каждый слот — `button.room-trophy-slot`, `data-spirit-id` через React key / spiritId.

| Параметр | Значение |
|----------|----------|
| Высота трофея (img) | **`3.8 vh`**, `width: auto` |
| Пустой слот (силуэт) | та же высота `3.8 vh`, ширина `3.8 vh` |
| `bottom` на полке | **`88%`** |
| Hit-area | `min-width/min-height: 44px` на кнопке |
| z-index | `41` (над полкой) |

**Горизонтальные позиции** (центр слота, `%` от ширины полки):

| Слотов на полке | Классы | `left` |
|-----------------|--------|--------|
| 1 | `--alone` | `50%` |
| 2 | `--left`, `--right` | `28%`, `72%` |
| 3 | `--triple-left`, `--triple-mid`, `--triple-right` | `22%`, `50%`, `78%` |

### 3.4. Распределение духов (порядок прогрессии `scenario.md` §5.3)

| Полка | Дух 1 | Дух 2 | Дух 3 |
|-------|-------|-------|-------|
| `wall-l-1` | Суседко | Банник | — |
| `wall-l-2` | Кикимора | Полевой | — |
| `wall-l-3` | Овинник | Леший | — |
| `wall-r-1` | Водяной | Топтыгин | Полудница |
| `wall-r-2` | Русалка | Лада | Велес |
| `wall-r-3` | Баба-Яга | Кощей | Чудо-Юдо |

Пути `spiritId` → `assets/trophies/` — **`assets_catalog.md`**. MVP-fallback: `creatures_in_the_book/[spirit].png`.

### 3.5. Состояния слота

| Состояние | Визуал | Поведение |
|-----------|--------|-----------|
| locked | Силуэт `?` в рамке, `opacity: 0.45` | Клик → «Ещё не встречен» |
| unlocked | 3D-трофей PNG | Клик → модалка мини-сказа |
| unlocked:hover | `scale(1.05)` | desktop |

### 3.6. Лавка (декор, 4-й ярус слева)

| Свойство | Значение |
|----------|----------|
| Класс | `.scene-bench-room2` |
| `left` | `35 vw` |
| `top` | `75 vh` |
| `width` | `14 vw` |
| z-index | `40` |
| Ассет | `assets/furniture/bench.png` |

Конфиг: `room2Bench` в `sceneLayout.ts`. Не путать со скамейкой комнаты 1 (`.scene-bench`).

При расширении коллекции — **добавляются только лавки** (см. §1 «Расширение коллекции»), не полки.

## 5. Адаптив

| Режим | Поведение |
|-------|-----------|
| Landscape 16:9 | Все 8 полок в кадре; pan из комнаты 1 |
