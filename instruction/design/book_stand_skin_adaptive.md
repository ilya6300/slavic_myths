## UX-решение

### Что видит игрок

- При смене скина избы в профиле книга **остаётся на полке** в правом углу — без скачка вверх/вниз или в сторону.
- Подставка и книга двигаются **согласованно** (один якорь, две дельты по `bottom`).
- На мобильном (`≤640px`) — те же правила; отдельная строка в таблице смещений.
- Анимация `book-idle` и hover §`book_layout.md` §1.1 — без изменений.

### Корневая причина (дизайн)

Скины `assets/house/hut_*.png` — **разные композиции** одной комнаты: угол под полку/книгу в кадре смещён (перспектива, декор, руны у `hut_the_age_of_miracles`).  
Фиксированные `76vw` / `9vh` калиброваны под `hut_standart` и ломаются на остальных.

**Не путать:** смена `object-position` у `.layer-izba__img` сдвинет **всю** мебель и кота — **запрещено**. Корректируем **только** `.scene-book-stand` и `.scene-book`.

## UI-описание

### Механизм (для разработчика)

1. На `.izba-room--1` и `.izba-room--2` (обе комнаты — один скин) добавить `data-izba-skin="{HouseSkinId}"` из `gameStore.skins.izba`.
2. Базовые координаты — **эталон `hut_standart`** (текущий `index.css`).
3. Per-skin — CSS-переменные на селекторе `[data-izba-skin="…"]`:

```css
.izba-room {
  --book-stand-left: 76vw;
  --book-stand-bottom: 2vh;
  --book-left: 76vw;
  --book-bottom: 9vh;
  --book-width: 6vw;
}

.scene-book-stand {
  left: var(--book-stand-left);
  bottom: var(--book-stand-bottom);
}

.scene-book {
  left: var(--book-left);
  bottom: var(--book-bottom);
  width: var(--book-width);
}
```

4. Мобильный блок — переопределение переменных **внутри** каждого `[data-izba-skin]` (не глобальный `.scene-book` без скина).

### Таблица смещений (эталон — `hut_standart` = 0)

Калибровка: визуально на **100vw landscape** и **375×667 portrait**; книга стоит на ледж подставки, корешок не «висит» в воздухе.

| `data-izba-skin` | Δ `book-stand-left` | Δ `book-stand-bottom` | Δ `book-left` | Δ `book-bottom` | Δ `book-width` | Примечание |
|------------------|---------------------|------------------------|---------------|-----------------|----------------|------------|
| `hut_standart` | 0 | 0 | 0 | 0 | 0 | эталон |
| `hut_rate` | 0 | 0 | 0 | 0 | 0 | композиция ≈ standart; проверить в билде |
| `hut_epic` | 0 | 0 | 0 | 0 | 0 | то же; файл может совпадать с rate |
| `hut_the_age_of_miracles` | **−1vw** | **+0.5vh** | **−1vw** | **+1vh** | 0 | руны на полу; стартовая дельта — уточнить по скрину |

#### Mobile `@media (max-width: 640px)` — база поверх desktop-переменных

| Скин | `book-bottom` (итог) | `book-width` | Δ к desktop-строке |
|------|----------------------|--------------|-------------------|
| все | `12vh` | `5.5vw` | +3vh bottom, −0.5vw width (уже в сессии) |
| `hut_the_age_of_miracles` | `13vh` | `5.5vw` | +1vh к моб. базе |

> Числа в таблице — **стартовые** для разработчика. Критерий приёмки: **визуально без скачка** при переключении всех 4 скинов в профиле, не совпадение цифр в таблице.

### Hit-area

- Кликабельная зона книги — существующий `SceneSprite` + `scene-book--interactive`; **не** увеличивать `width` ради 44px.
- Если после калибровки hit-area < 44px на мобильном — невидимый `::before` на `.scene-book` (протокол `css-styling.mdc`), без растягивания PNG.

### Состояния

| Состояние | Поведение |
|-----------|-----------|
| Смена скина в профиле | Мгновенная пересадка по `data-izba-skin`, без анимации скачка |
| Overlay книги открыт | `.izba-scene--book-overlay .scene-book { visibility: hidden }` — без изменений |
| Hover / idle | Без изменений (`book_layout.md` §1.1) |

## Layout vs mockup

| Зона | Выравнивание | Ширина / fit | CSS |
|------|--------------|--------------|-----|
| Подставка | якорь `left` + `translateX(-50%)` | натуральный PNG | `.scene-book-stand` + `--book-stand-*` |
| Книга на подставке | тот же `left`, выше на `bottom` | `--book-width` (6vw / 5.5vw mob) | `.scene-book` |
| Скин избы | не трогать | `object-position: center bottom` | `.layer-izba__img` |

### Не путать

- Сдвиг фона избы ≠ посадка мебели.
- Полёт книги в центр (FLIP) ≠ координаты на полке.

## Визуальные решения

- Материалы без изменений: `stand.png`, `book_of_spirits.png`, скины `house/hut_*.png`.
- Новые ассеты **не нужны** (P0). Если после калибровки угол на `hut_epic` не сходится — эскалация: правка PNG художником (P2), не костыль `scale` на всю избу.
