## Обычный сундук (кулдаун 3 ч)

| Параметр | Значение |
|----------|----------|
| Кулдаун | 3 часа после открытия |
| Первое открытие (после Суседко) | Таймер = 0, сразу готов |
| Шанс фрагмента Эпохи | **~0,5%** (extra-roll 50 / пул 10050); дизайн-верхняя граница ≤ 5% |
| Дубликат скина / титула | → 1 фрагмент выбранного эпика **или** утешительный приз |
| Титулы Эпохи чудес | **Не выпадают** (только Сундук чудес) |
| Грейд epoch в пуле | Скины и прочее, **без** сундучных epoch-титулов |

### Содержимое пула (типы наград)

Скины: кот, домовой, изба, окно · титулы: common / rare / epic · ключи к духам · +50 энергии (common) · тайные обереги · фрагменты (редко).

## Сундук чудес (еженедельное событие)

| Параметр | Значение |
|----------|----------|
| Появление | Раз в 7 дней (локальный пн 00:00) |
| Условие | Суседко побеждён + ≥ 1 редкий дух |
| 1-е открытие цикла | Бесплатно |
| Дальше | **700** кликов **или** Яндекс Pay |
| Прогресс кликов | Не сбрасывается в понедельник |

### Шанс фрагмента

| Исход | Шанс |
|-------|------|
| Фрагмент выбранному locked-духу | **25%** |
| Pity (8-е открытие подряд без фрагмента) | **100%** гарант фрагмента |
| Все фрагментные духи открыты | Только утешительный пул |

### Утешительный пул (если не фрагмент)

Веса (`miracleConsolationWeights`, сумма 8200):

| Награда | Вес | Относительная частота |
|---------|-----|----------------------|
| Тайные обереги ×2 | 2800 | Часто |
| Полная энергия (+100) | 2600 | Часто |
| Ключ к обычному сундуку | 700 | Средне |
| Ключ к духу (Полудница / Топтыгин / Русалка) | 900 | Средне |
| Эпический титул | 600 | Реже |
| Эпический скин избы | 500 | Реже |
| Титул Эпохи чудес | 100 | **Самый редкий** среди утешительных |

Дубликаты: реролл **или** +2 оберега (титулы) / ключ к обычному сундуку (скин избы).

## Дубликаты коллекций

| Ситуация | Результат |
|----------|-----------|
| Дубликат скина / титула из сундука | 1 фрагмент эпика **или** утешительный (+30 энергии / +1 оберег, если всё собрано) |
| Дубликат титула (утешительный пул чудес) | +2 оберега |

Параметры fallback: `duplicateHandling` — 30 энергии, 1 оберег, +2 оберега за дубликат титула.
