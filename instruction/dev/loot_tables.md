## Обычный сундук (кулдаун 3 ч)

| Параметр | Значение |
|----------|----------|
| Кулдаун | 3 часа после открытия |
| Первое открытие (после Суседко) | Таймер = 0, сразу готов |
| Шанс фрагмента Эпохи | **≤ 5%** на выбранный / ближайший locked |
| Дубликат скина / титула | → 1 фрагмент выбранного эпика **или** утешительный приз |
| Титулы Эпохи чудес | **Не выпадают** (только Сундук чудес) |
| Грейд epoch в пуле | Скины и прочее, **без** сундучных epoch-титулов |

### Содержимое пула (типы наград)

Скины: кот, домовой, изба, окно · титулы: common / rare / epic · ключи к духам · сметана · тайные обереги · фрагменты (редко).

### Веса внутри пула (ориентир, пул 10000)

| Грейд / тип | Базовый вес | С удачей (+10% rare+) |
|-------------|-------------|------------------------|
| common | ~5300 | — |
| rare | ~3000 | +10% |
| epic | ~1500 | +10% |
| epoch (скины, не титулы) | ~200 | +10% |

> Точные веса по каждому предмету — в `lootTables.ts` при реализации.

## Сундук чудес (еженедельное событие)

| Параметр | Значение |
|----------|----------|
| Появление | Раз в 7 дней (локальный пн 00:00) |
| Условие | Суседко побеждён + ≥ 1 редкий дух |
| 1-е открытие цикла | Бесплатно |
| Дальше | 1000 кликов **или** Яндекс Pay |
| Прогресс кликов | Не сбрасывается в понедельник |

### Шанс фрагмента

| Исход | Шанс |
|-------|------|
| Фрагмент выбранному locked-духу | **25%** |
| Pity (8-е открытие подряд без фрагмента) | **100%** гарант фрагмента |
| Все фрагментные духи открыты | Только утешительный пул |

### Утешительный пул (если не фрагмент)

| Награда | Относительная частота |
|---------|----------------------|
| Тайные обереги ×2 | Часто |
| Сметана (полная энергия) | Часто |
| Ключ к обычному сундуку | Средне |
| Ключ к духу (Полудница / Топтыгин / Русалка) | Реже |
| Эпический титул | Реже |
| Эпический скин избы | Реже |
| Титул Эпохи чудес | **Самый редкий** среди утешительных |

Дубликаты: реролл **или** +2 оберега (титулы) / ключ к обычному сундуку (скин избы).

### Фоновые источники фрагментов (не основной канал)

| Источник | Эффект |
|----------|--------|
| Обычный сундук | ≤ 5% |
| Дубликат из обычного сундука | 1 фрагмент |
| Победа над редким+ (Леший, Водяной, Топтыгин, Полудница, Русалка) | +1 разово |
| Первый Жирдяй за неделю (пост-MVP) | +1 |
