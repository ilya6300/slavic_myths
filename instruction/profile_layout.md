# HUD-аватар и экран профиля — техническая спека дизайна

> **Версия:** 1.0  
> **Дата:** 2026-08-28  
> **Автор:** гейм-дизайнер UI/UX  
> **Канон коллекций:** `scenario.md` §9 · `tituls.md` · `assets_catalog.md`  
> **Слои сцены:** `izba_scene_layers.md`  
> **Рамки грейда (есть в репо):** `assets/frame/`

## 1. UX-решение

На сцене избы **нет** отдельной кнопки «инвентарь». Игрок видит **морду своего кота** слева сверху и **титул рядом**. Тап по аватарке — единственный вход в профиль (экипировка скинов и титулов).

| Было (отменяется) | Стало |
|-------------------|--------|
| Титул отдельным бейджем слева / снизу слева / справа в HUD | Титул **только** справа от аватарки, одна строка |
| «Список титулов — пост-MVP» | Профиль в scope: скины + титулы, включая неполученные |

Одна главная задача на экране профиля: **посмотреть, как вещь сидит в мире, и экипировать, если она есть**.

Тапов: аватар (1) → ячейка сетки (1) → «Выбрать» (1, только если вещь своя). Закрыть: × или тап по затемнению.

## 2. HUD — чип профиля (изба и трофеи)

`.layer-hud`, `position: fixed`, не участвует в pan. Safe-area: `top: max(8px, env(safe-area-inset-top))`.

**Шапка целиком, рельс дара/Кикиморы, запрет CSS-дерева:** `hud_layout.md` (канон раскладки 2026-09-10). Ниже — только чип «морда + титул».

```
┌──────────────────────────────────────────────────────────────────┐
│  ┌────┐ Новенький                 [⚡ 87/120]  [🪙 142] [🛡 3] [🌿 2/3] │
│  │морда│ ← .hud-profile            центр          правый кластер │
│  └────┘                                                          │
│  [🎁 Дар путника]  ← .hud-rail, не в этом чипе                   │
│  [🧶 Кикимора]                                                   │
└──────────────────────────────────────────────────────────────────┘
```

Ресурсы **не** уезжают в профиль. Они остаются в HUD: энергия — **центр шапки**; монеты, обереги, **трава (`n/3`)**, сметана — правый верх. Кикимора и дар **не** внутри `.hud-profile`. Трава — `hud_layout.md` §4.1.

### 2.1. Чип `.hud-profile`

Один `button`. Клик по **аватарке** открывает профиль; титул — текст в том же button (крупнее зона, без второго контрола).

| Элемент | Класс | Правило |
|---------|-------|---------|
| Аватар | `.hud-avatar` | Кроп **морды** активного скина кота, не полный sit |
| Рамка аватара | `.hud-avatar__frame` | Рамка грейда **экипированного скина кота** (`assets/frame/…`) |
| Титул | `.hud-title` | Активный `titleId` из `tituls.md`, 1 строка |
| Грейд титула | цвет/вес текста, без второй рамки вокруг слов | common — `#f5e6d0`; rare — `#9ad4c8`; epic — `#c9a0ff`; epoch — `#f0c14a` |

### 2.2. Размеры HUD-аватара

| Параметр | Desktop | Mobile |
|----------|---------|--------|
| Внешний квадрат (рамка) | 56×56 px | 48×48 px |
| Touch target чипа | min высота 48 px, ширина аватар + титул + 8 px padding | то же |
| Титул | 15 px, `#f5e6d0`, max 18 ch, иначе `…` | 14 px, max 14 ch |
| Позиция чипа | `top: 8px; left: 8px` | то же + safe-area |
| Зазор аватар→титул | 8 px | 6 px |

Источник морды (MVP, без отдельных PNG):

```
object-fit: cover;
object-position: 50% 18%;   /* глаза/лоб sit-спрайта */
```

Спрайт: `[skin]_sid.png` активного `skins.cat`. Sleep-спрайт в HUD **не** используется.

P2 (не блокирует): `assets/pets/{grade}/{id}/{id}_avatar.png` — готовая морда; если файла нет, кроп.

### 2.3. Состояния чипа

| Состояние | Визуал |
|-----------|--------|
| Idle | рамка грейда, титул читается на тёмной плашке `rgba(40, 28, 18, 0.72)` |
| Hover (desktop) | `scale(1.03)` аватара |
| Active | `scale(0.97)` |
| Профиль открыт | чип без дополнительного «вдавливания»; модалка сверху |
| Жирдяй активен | чип **кликабелен** (профиль не блокируется, `scenario.md` §7.3) |

`aria-label`: «Профиль. [Титул]. Скин кота: [имя скина]».

## 3. Модалка профиля `.profile`

`z-index: 200` (`.layer-modal`). Затемнение `rgba(12, 8, 5, 0.72)`. Свайп избы выключен.

```
┌─────────────────────────────────────────────────────────────────┐
│ [×]  Профиль                                                    │
│                                                                 │
│  ┌──────────────────────┐   [Кот] [Изба] [Лес] [Домовой] [Титулы]│
│  │                      │                                       │
│  │   ПРЕВЬЮ             │   ┌────┐ ┌────┐ ┌────┐ ┌────┐        │
│  │   «где это надо»     │   │рамка│ │    │ │    │ │    │        │
│  │                      │   └────┘ └────┘ └────┘ └────┘        │
│  │  Имя · грейд         │   … сетка, скролл …                   │
│  │  Описание (1–2 фразы)│                                       │
│  │  Откуда: Сундук /    │                                       │
│  │          квест       │                                       │
│  │  [ Выбрать ] | —     │                                       │
│  └──────────────────────┘                                       │
└─────────────────────────────────────────────────────────────────┘
```

### 3.1. Колонки

| Сторона | Доля ширины desktop | Mobile (portrait и landscape ≤520px высоты) |
|---------|---------------------|--------|
| Левая — превью | `minmax(240px, 38%)` | **30%** ширины модалки, слева, на всю высоту блока layout; мета и «Выбрать» — под превью в этой колонке |
| Правая — вкладки + сетка | остаток | **70%**; вкладки — **сетка 3×N**, компактный шрифт (~0.58rem), сверху правой колонки; **скролл только `.profile-grid`**, не панель и не оверлей |
| Панель | `min(94vw, 720px)` | `100vw` × `100dvh`, `overflow: hidden` |

Панель: дерево / тёмный ус (`rgba(32, 22, 14, 0.94)`), уголки как у `dialog_frame_wood` / fallback викторины. Не Material-карточка и не стекло iOS.

Кнопка × : верхний правый угол панели, 44×44, деревянная. `aria-label`: «Закрыть профиль».

### 3.2. Вкладки `.profile-tabs`

Пять вкладок — **все** коллекции, которые игрок экипирует (трофеи и духи книги сюда **не** входят: у них свои экраны).

| ID | Подпись | Store | Превью «где это надо» |
|----|---------|-------|------------------------|
| `cat` | Кот | `skins.cat` | **Только** `sit` выбранного скина (без избы и леса) |
| `izba` | Изба | `skins.izba` | **Только** PNG выбранного скина избы |
| `window` | Лес | `skins.window` | **Только** пейзаж; если ночь в игре — ночной фильтр |
| `brownie` | Домовой | `skins.domovoy` | **Только** PNG домового |
| `title` | Титулы | `titleId` | Текст титула над котом + `sit` экипированного кота (без рамки HUD) |

Вкладки — деревянные плашки (как ответ викторины), текст 14–15 px, без векторных иконок. Активная — светлее / золотой кант `2px #c9a227`.

Hit-area вкладки ≥ 44 px по высоте.

### 3.3. Вкладка «Атмосфера» (Epic 15)

Отдельная вкладка `atmosphere` рядом с коллекциями скинов. Одновременно активен **ровно один** owned-эффект или **none** («Без эффекта»). Победа над Перуном добавляет владение `thunder_izba`, но **не** включает эффект и не открывает вкладку автоматически.

| Карточка | Состояние | UI |
|----------|-----------|-----|
| Без эффекта | always | «Выбрать» / «Выбрано» — снимает любой эффект |
| Грозовая изба | locked | подсказка «Победите Перуна», без кнопки |
| Грозовая изба | owned | «Выбрать» |
| Грозовая изба | equipped | «Выбрано» |

Preview в левой колонке: мягкое затемнение + намёк на молнию (изолированно от live-сцены). `prefers-reduced-motion`: только статичное затемнение в preview и на сцене. Каталог эффектов расширяемый; в этой итерации runtime-ID — `thunder_izba` (см. `instruction/dev/tech.md` §Epic 15).

## 4. Левое превью `.profile-preview`

Превью показывает вещь **в контексте сцены**, не иконку в вакууме.

| Правило | Как |
|---------|-----|
| Кадр | 16:9, `object-fit: contain`, фон `#0a0705` |
| Слои внутри превью | тот же порядок, что `izba_scene_layers.md` §1, но без HUD |
| Жирдяй | в превью **нет** (это не примерка врага) |
| Недоступная вещь | превью **в цвете** (чтобы «посмотреть»); фильтр только на ячейке сетки |
| Смена ячейки | crossfade 0.2 s |

Под превью, не поверх арта:

| Поле | Источник |
|------|----------|
| Имя | каталог скина / `tituls.md` |
| Грейд | бейдж `badge_grade_*` или цвет подписи; для MVP — текст «Обычный / Редкий / Эпик / Эпоха чудес» |
| Описание | 1 фраза (титул — колонка «Описание для UI»; скин — короткое имя породы/темы) |
| Откуда | «Стартовый», «Сундук (3 ч)» (кот common/rare), «Сундук чудес» (кот epic/epoch, титулы epoch), «После [дух]», «Ночь, Жирдяй» |

### 4.1. Кнопка «Выбрать»

| Условие | UI |
|---------|----|
| Вещь **в коллекции** и **не** экипирована | кнопка «Выбрать», деревянная, высота ≥ 48 px |
| Вещь экипирована | не кнопка: статичный текст «Выбрано» |
| Вещи **нет** у игрока | кнопки **нет** (не disabled — отсутствие). Под описанием: «Ещё не получен» |

Нажатие «Выбрать» → action store → превью и HUD обновляются сразу → persist через `SaveService`. Модалка **не** закрывается.

## 5. Сетка `.profile-grid`

Все предметы вкладки видны всегда: и свои, и чужие. Пустая сетка запрещена (стартовый скин/титул «Новенький» всегда есть).

### 5.1. Ячейка

```
button.profile-cell
  .profile-cell__art     ← превью скина / глиф титула
  img.profile-cell__frame ← рамка грейда этой вещи
  .profile-cell__mark    ← точка «надето», если экипировано
```

| Параметр | Значение |
|----------|----------|
| Колонки desktop | 4 |
| Колонки mobile | 3 |
| Сторона ячейки | сетка `1fr`, gap 10 px |
| Рамка | грейд **ячейки**, не грейд экипированного кота |
| Hit-area | вся ячейка ≥ 44 px |
| Порядок | по грейду `common → rare → epic → epoch`, внутри — стабильный id |

Титул в сетке: не морда кота, а **текст титула** на пергаментном поле внутри рамки (2–3 слова, 12–13 px, центр). Не иконка «свиток» из вектора.

### 5.2. Рамки грейда — реальные файлы

Код грейда в логике: `common` \| `rare` \| `epic` \| `epoch`. На диске папки/файлы часто названы **`rate`** и **`the_age_of_miracles`**.

| Грейд (код) | Рамка | Примечание |
|-------------|-------|------------|
| `common` | `assets/frame/common.png` | тёплое резное дерево |
| `rare` | `assets/frame/rate.png` | дерево + патина, трава по краю |
| `epic` | `assets/frame/epic.png` | тёмная, фиолетовые кабошоны |
| `epoch` | `assets/frame/the_age_of_miracles.png` | камень, оранжевые руны |

Центр этих PNG сейчас **чёрный непрозрачный**. Класть PNG *поверх* арта нельзя — закроет скин.

**Сборка ячейки:**

1. `.profile-cell__art` — квадрат с внутренним отступом ≈ 14–18% стороны (толщина рамы).
2. `.profile-cell__frame` — `position: absolute; inset: 0; pointer-events: none`.
3. Пока центр чёрный: у frame-картинки CSS  
   `mix-blend-mode` **запрещён**; вместо этого кадрировать раму через `mask` **или** (надёжный MVP) `border-image` / девять нарезки, арт только во внутреннем box.  
4. P0 арт: вырезать чёрный центр рамок в альфу — тогда overlay как у окна избы.

Каталожные имена `assets/ui/frame_item_*.png` / `frame_avatar_*.png` — **не использовать**, файлов нет. Источник рамок — `assets/frame/`.

Аватар в HUD использует ту же четвёрку файлов.

### 5.3. Неполученное `.profile-cell--locked`

На **изображении в сетке** (арт + рамка):

```css
.profile-cell--locked .profile-cell__art,
.profile-cell--locked .profile-cell__frame {
  filter: grayscale(0.88) brightness(0.52) saturate(0.35);
  opacity: 0.78;
}
```

- Ячейка **кликабельна** — открывает превью слева.
- «Выбрать» нет (см. §4.1).
- Отдельный замок-PNG не обязателен (не плодить UI-ассет). Достаточно фильтра + строки «Ещё не получен».
- `aria-label`: «[Имя], [грейд], не получен».

Экипированная ячейка: без фильтра, золотая точка 8 px в углу `.profile-cell__mark`, `aria-current="true"`.

Своя, но не надета: полный цвет, без точки, есть «Выбрать».

## 7. Данные, без которых UI не собрать

В `GameSave` сейчас есть экип (`skins`, `titleId`), но **нет** списка владения. Для сетки нужно (архитектору / `tech.md`):

```ts
ownedSkinIds: string[];   // 'cat:cat_standart', 'izba:hut_standart', …
ownedTitleIds: string[];  // 'novichok', …
```

Дефолт при первом запуске: стандартный кот, стандартная изба, стандартный лес, стандартный домовой (экип домового не виден на сцене до победы), титул «Новенький».

Без `owned*` нельзя отличить «смотреть» от «выбрать». Не хранить владение только в DOM.

Символ × в проде — вырезанный деревянный крестик PNG (⏳ P2) или глиф в деревянном квадрате; не Material `Close`.

## 10. Чеклист приёмки дизайна

- [ ] Титул не живёт отдельным блоком слева/снизу — только справа от морды
- [ ] Клик по аватарке открывает профиль; ресурсы HUD на месте
- [ ] Слева превью контекста, справа сетка
- [ ] Каждая ячейка в рамке **своего** грейда из `assets/frame/`
- [ ] Неполученное: в сетке есть, смотреть можно, «Выбрать» нет, фильтр на арте ячейки
- [ ] Полученное не экипированное: «Выбрать» есть
- [ ] Экипированное: «Выбрано», точка на ячейке
- [ ] Вкладки: кот, изба, лес, домовой, титулы
- [ ] Нет SVG-иконок и flat-карточек
- [ ] Жирдяй не рисуется в превью профиля
